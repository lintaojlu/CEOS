# CEOS 视觉

黑白负责界面。橙色只负责警告。蓝色只留在活跃情况统计，以及任务正文里识别到的时间。

## 颜色

### 黑白

| 角色 | 值 | 用在 |
| --- | --- | --- |
| 纸 | `#FFFFFF` | 页面、侧栏、卡片 |
| 凹槽 | `#F4F4F5` | 输入框、分段控件、选中、悬停、卡片内的小块 |
| 墨 | `#111111` | 标题、正文强调、主按钮、焦点、今天、进度、勾选 |
| 按下 | `#000000` | 主按钮按下 |
| 次墨 | `#3F3F46` | 正文 |
| 弱 | `#71717A` | 说明 |
| 淡 | `#A1A1AA` | 眉题、占位 |
| 线 | `rgba(0,0,0,0.08)` | 分割 |
| 粗线 | `rgba(0,0,0,0.16)` | 按钮边、输入框边、选中日期的边 |

主按钮是墨底白字。选中导航、悬停、拖放命中用凹槽底，不用彩色。已完成与普通强调都是墨色。任务正文里识别到的时间用 `#2563EB`，只标那几个字。

### 警告

只此一组橙色。`#E14A0E`，浅底 `rgba(225,74,14,0.08)`。

用在：设置提示、逾期、删除悬停。字用本色，不用白字小标签。

### 活跃

完成率从灰走到蓝。这是界面里唯一保留的蓝色。无数据是灰。还没到的日期透明，只留 `rgba(0,0,0,0.16)` 的内描边。

| 档 | 值 |
| --- | --- |
| 无数据 | `#E4E4E7` |
| 0 | `#D6E2F5` |
| 低，不超过 40% | `#93B4F5` |
| 中，不超过 80% | `#3B6FE8` |
| 高，80% 以上 | `#1D4ED8` |

日历里的完成条、年视图小格用同一组。日期选中和「今天」仍是墨色。

## 设计语言

排版不改。圆角沿用现在的：卡片 16，控件 10，按钮 9。

靠 1px 线分层，不靠阴影。阴影只给浮层：弹窗和热力图提示，`0 10px 28px rgba(0,0,0,0.12)`。

标题 Fraunces，中文回落宋体。正文 Inter。日期、眉题、等宽标签 JetBrains Mono。

动效保持 `cubic-bezier(0.22, 1, 0.36, 1)`，只做颜色和位移，时长不超过 0.2s。

## 图标

改界面时先对照这一节，不要另起一套尺寸。

界面图标：24 视口，18px，线宽 1.8，圆头圆角，`currentColor`。跟文字走，默认墨色。主按钮里的图标是白色。

标志：白底圆角方块，黑色圆角 C，开口里一个圆点。C 的转角和端点都是圆的。标志不改成蓝，也不改成橙。

侧栏和 favicon 用满幅 `public/logo.svg`（128 视口，白底圆角 `rx="28"`，约边长的 22%）。这块是界面里的小标，不要再缩小。

启动栏（Dock）是另一套，按这张表，不要只改其中一项：

| 参数 | 值 |
| --- | --- |
| 画布 | `1024×1024` |
| 白底占比 | `0.80`，边长 `819`，居中，四周各留 `102` |
| 白底圆角 | 白底边长的 `0.224`，半径 `183` |
| 圆角外 | 透明。不要铺白，否则 Dock 里是直角方块 |
| 图形 | 与 128 视口的 C 同一比例，画在这 819 的白底里 |
| 验收 | `icon.png` 为 512 时，不透明区域约 `(48, 48, 463, 463)`，约占边长 `0.81` |

白底铺满 1024 会比旁边的应用大一圈。只留圆角、不留这 20% 透明边，尺寸就不对。用 SVG 跑 `tauri icon` 会把透明边裁掉，白底又铺满。导出必须从带透明边的 1024 PNG 来。图标打进二进制，换文件后要重新编译，并刷新 Dock，启动栏才会变。

| 文件 | 格式 | 用途 |
| --- | --- | --- |
| `public/logo.svg` | SVG | 侧栏、favicon |
| `docs/assets/logo.svg` | SVG | 文档里的标志 |
| `docs/assets/logo-banner.svg` | SVG | 浅色横幅 |
| `docs/assets/logo-banner-dark.svg` | SVG | 深色横幅 |
| `src-tauri/app-icon.svg` | SVG | 桌面图标源稿，满幅 |
| `src-tauri/icons/icon.png` | PNG | 通用位图，四周留白，白底块约占 80% |
| `src-tauri/icons/32x32.png`、`64x64.png`、`128x128.png`、`128x128@2x.png` | PNG | 各尺寸 |
| `src-tauri/icons/Square*.png`、`StoreLogo.png` | PNG | Windows 商店尺寸 |
| `src-tauri/icons/ios/AppIcon-*.png` | PNG | iOS |
| `src-tauri/icons/android/mipmap-*/ic_launcher*.png` | PNG | Android |
| `src-tauri/icons/android/mipmap-anydpi-v26/ic_launcher.xml`、`values/ic_launcher_background.xml` | XML | Android 自适应图标 |
