## Agent 接入方案讨论

- 讨论了如何让 WorkBuddy、Codex、OpenClaw 等 Agent 产品通过自然语言操作 CEOS，例如“明天三点帮我加一个会议”。
- 关键判断：当前 CEOS 的业务数据主要存放在浏览器本地状态里，后端只暴露 `/api/ai-eval`；若要被 Agent 稳定调用，需要增加一个可鉴权的后端操作接口和共享数据层。
- 推荐路线：先做 CEOS API 层（如 `/api/tasks`、`/api/milestones`、`/api/daily-reflection`），再封装 MCP Server 或 WorkBuddy Skill，让 Agent 调用结构化工具，而不是模拟浏览器点击。
